# Анализ встреч · PRO

Next.js показывает записи и конспекты. Python принимает MP4/WebM с компьютера или по публичной ссылке Яндекс Диска. FFmpeg извлекает аудио, локальный Whisper распознаёт речь, API из RAG-проекта получает расшифровку и составляет конспект. SQLite хранит этапы, историю, расшифровки и результаты. SHA-256 позволяет открыть готовый конспект для того же файла, в том числе если он добавлен другим способом.

## Запуск

Нужны Python 3.11+, Node.js 20.9+, FFmpeg, FFprobe, whisper-cli и локальная многоязычная GGML-модель Whisper.

1. В корне проекта создайте виртуальное окружение и установите зависимости:
   ```sh
   python3 -m venv .venv
   .venv/bin/pip install -r backend/requirements.txt
   cp .env.example .env
   ```
2. В `.env` укажите путь к модели Whisper. Заполните `LLM_BASE_URL`, `LLM_API_KEY` (или `LLM_API_KEY_FILE`) и `LLM_MODEL` значениями из серверной конфигурации RAG-проекта.
3. В корне проекта запустите API одним процессом:
   ```sh
   .venv/bin/uvicorn backend.main:app --port 8000
   ```
4. В другом терминале запустите интерфейс:
   ```sh
   cd frontend
   npm ci
   npm run dev
   ```
   Откройте http://localhost:3000.

## Проверка

Вставьте публичную ссылку вида `https://disk.yandex.ru/i/…` на согласованный учебный MP4 или WebM длительностью 2–5 минут. После обработки откройте конспект и расшифровку, обновите страницу и откройте их снова. Вставьте ту же ссылку повторно и воспользуйтесь кнопкой «Открыть готовый результат». Проверьте запасной путь с загрузкой файла с компьютера.

Размер записи ограничен 150 МиБ, длительность — 6 минут. При недоступной облачной ссылке можно загрузить видео с компьютера. Записи обрабатываются последовательно. Временные медиа удаляются по завершении обработки.

## Публикация

Для Vercel укажите `frontend` как корень приложения и задайте `NEXT_PUBLIC_MEETING_API` с HTTPS-адресом Python API. Серверу Python нужны Whisper, FFmpeg, постоянный каталог `MEETING_STORAGE` и `FRONTEND_ORIGINS` с адресом интерфейса. Для публикации задайте на Python-сервере длинный случайный `MEETING_ACCESS_KEY` и передайте код преподавателю отдельно. Код открывает общую историю демонстрационного экземпляра.

Опубликованный экземпляр: [Анализ встреч на Vercel](https://meeting-analyzer-blush.vercel.app/). Для просмотра готового результата откройте синтетическую демозапись в истории. Учебная проверка облачного импорта требует публичной ссылки на короткий файл Яндекс Диска с доступным скачиванием.
